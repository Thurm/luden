## Interface Change Declaration Template (Phase 2)

```markdown
# Interface Change Declaration — Module {N}: {Module Name}

## Data Model Changes

### [ModelName] — [new / extended]
| Change | Field | Type | Backward compatible? | Reason |
|---|---|---|---|---|
| Add field | fieldName | type | Yes — new optional field | [why needed] |

## System Signature Changes

### [SystemName]
| Change | Detail | Backward compatible? | Reason |
|---|---|---|---|
| New constructor param | paramName: Type | Yes — existing params unchanged | [why needed] |
| New method | methodName(args): Return | Yes — additive only | [why needed] |

## Event Changes

| Change | Event name | Payload | Backward compatible? | Reason |
|---|---|---|---|---|
| New event | event:name | { field: type } | Yes — new event | [why needed] |

## Store Changes

### [storeName]
| Change | Field/Action | Type | Backward compatible? | Reason |
|---|---|---|---|---|
| New field | fieldName | type | Yes — additive | [why needed] |
| New action | actionName(args) | — | Yes — additive | [why needed] |

## Configuration Changes

| Change | File | Detail |
|---|---|---|
| New file | config-name.json | [purpose] |
| Extend | existing-config.json | Add field: fieldName | 

## Bootstrap Chain Impact
- New system: [SystemName] — insert after step N, depends on [X, Y]
- Modified injection: [SystemName] now also receives [new dependency]

## Compatibility Summary
- All changes above: [ARE / ARE NOT] backward compatible
- Affected existing modules: [list or "none"]
- Migration steps required: [list or "none"]
```
