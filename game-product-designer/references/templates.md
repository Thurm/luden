## GDD Template (Phase 3 Output)

```markdown
# {Game Name} — Game Design Document (GDD)

> Generated by game-product-designer pipeline
> Source idea: "{original user input, verbatim}"
> Date: {date}

---

## Chapter 1: Product Overview

### 1.1 Elevator Pitch
[One sentence: What is this game?]
[One sentence: Who is it for?]
[One sentence: Why would they play it over alternatives?]

### 1.2 Genre & Positioning
[Genre tag hierarchy from Phase 0]
[Competitive landscape summary — key references and how this game differs]

### 1.3 Target Audience
[Primary audience persona — age, gaming habits, motivation type]
[Secondary audience, if any]

### 1.4 Platform & Tech Direction
[Target platforms with confirmed input method and session length expectation]
[Recommended tech stacks (2-3 candidates) with tradeoffs]
[Distribution constraints]

### 1.5 Monetization Direction
[Monetization model, or "To be determined" with reasoning]

---

## Chapter 2: Core Gameplay

### 2.1 The 30-Second Loop
[Stimulus → Decision → Action → Feedback cycle]
[What makes this loop feel good?]
[GDP-002 check: Does the 30s loop have standalone fun without meta-game?]

### 2.2 The 5-Minute Loop
[Session arc: entry → core gameplay → exit → hook]
[Expected session length and frequency]
[GDP-003 check: Player scenario and session mode rationale]

### 2.3 Core Fun Factors
[Top 2-3 fun factors with concrete examples of where they appear]

### 2.4 Player Motivation Profile
[Directional Bartle mapping or equivalent]

---

## Chapter 3: System Overview

### 3.1 Module Map
[Table: all modules with priority, MVP status, and one-line description]

### 3.2 Module Dependencies
[Dependency diagram or matrix]
[Critical path: which modules must be built in what order?]

### 3.3 MVP Definition
**MVP includes**: [list of P0 + P1 modules with brief justification]
**MVP does NOT include**: [P2/P3 modules with reason for deferral]
**MVP success criteria**: [3-5 statements about what "done" looks like]
[GDP-001 check: MVP constructs a complete experience loop?]

### 3.4 Differentiation Declaration
[1-2 core differentiators]
[For each: 可感知? 可描述? 可验证? — GDP-004 three-criteria test]

---

## Chapter 4: Module Details (MVP)

### 4.N [Module Name]
**Priority**: P0/P1
**Responsibility**: [one sentence]

**Core Features**:
- [feature 1]
- [feature 2]
- [feature 3]

**Experience Design Intent** (GDP-006):
- **Core Decisions** (1-3): [What meaningful choices does the player make in this module?]
- **Satisfaction Moments** (1-2): [When exactly does the player feel excited/satisfied?]
- **Strategy Space**: [Multiple viable strategies, or single dominant path? Describe.]

**Depends On**: [list]
**Design Considerations**:
- [key question or risk]
**Estimated Complexity**: Simple / Medium / Complex

[Repeat for each MVP module]

---

## Chapter 5: Content Plan (High-Level)

[How many [entities] does the MVP need? e.g., characters, levels, items]
[This is an order-of-magnitude estimate, not a detailed content list]

### 5.2 Art Style Direction
[High-level art style — e.g., "pixel art", "low-poly 3D", "hand-drawn 2D"]
[Reference art styles from existing games if helpful]

### 5.3 Narrative Scope
[Does the game have a story? If so, what's the structure?]
[MVP narrative scope vs full game narrative scope]
```
